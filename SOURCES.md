# Data and resources

These are the resources actually used, separated from challenge links that were only reviewed. The JSON packs retain source product identifiers, coordinate systems, source hashes, processing notes and limitations. NASA data values were not generated by AI.

## NASA and USGS data used

| Resource | Use in Terrain Surf |
| --- | --- |
| [USGS Mars 2020 HiRISE 1 m DTM](https://astrogeology.usgs.gov/search/map/Mars/Mars2020/JEZ_hirise_soc_006_DTM_MOLAtopography_DeltaGeoid_1m_Eqc_latTs0_lon0_blend40) | Measured terrain, elevation, derived slope and route sampling. Cropped, converted to browser height arrays and corrected for the local ground scale. |
| [USGS Mars 2020 HiRISE 25 cm orthomosaic](https://astrogeology.usgs.gov/search/map/Mars/Mars2020/JEZ_hirise_soc_006_orthoMosaic_25cm_Eqc_latTs0_lon0_first) | Registered optical minimap and terrain texture. Display conversion/contrast and illustrative colour are distinct from measured relief. |
| [NASA SuperCam close-up of Máaz](https://science.nasa.gov/resource/supercam-close-up-of-maaz/) | Archived rock observation, PIA24493, sol 12. |
| [NASA SuperCam close-up of Yeehgo](https://science.nasa.gov/resource/supercam-close-up-of-yeehgo-yeigo-target/) | Archived rock observation, PIA24492, sol 16. |
| [PDS SuperCam observation log](https://pds-geosciences.wustl.edu/m2020/urn-nasa-pds-mars2020_supercam/data_observation_log/m2020_scam_masterlist.csv) | Observation identifiers, times and site/drive joins. |
| [PDS PLACES rover localizations](https://pds-geosciences.wustl.edu/m2020/urn-nasa-pds-mars2020_rover_places/data_localizations/best_interp.csv) | Approximate observation-station localization and historical MEDA station interval. Not exact rock coordinates. |
| [NASA PDS MEDA archive](https://atmos.nmsu.edu/data_and_services/atmospheres_data/PERSEVERANCE/meda.html) | Historical Perseverance pressure and local mast air temperature, sol 16; selected stable-station interval and gaps retained. |
| [NASA Mars atmospheric aerosols / MRO MCS](https://pds-atmospheres.nmsu.edu/data_and_services/atmospheres_data/MARS/aerosols.html) | NASA instrument/archive context for the producer's regional dust product below. |
| [NASA-hosted camera reference](https://ntrs.nasa.gov/api/citations/20220013651/downloads/Guzewich.hexagonal.STI.pdf) | Navcam frame dimensions and field of view reference; browser approximation, not calibrated camera simulation. |
| [JPL Mars 2020 mobility](https://www-robotics.jpl.nasa.gov/what-we-do/flight-projects/mars-2020-rover/m2020mobility/) | Mobility context and separation of terrain planning from validated rover dynamics. |

Terrain and orbital imagery credit: **NASA/JPL/University of Arizona/USGS**. Observation-specific credits remain in the science pack and observation viewer.

Inspect [landing terrain](data/terrain_detail.json), [north terrain](data/jezero_north/terrain.json), [science records](data/science_v006/science.json), [MEDA records](data/weather_v009/weather.json), and [regional dust records](data/regional_v011/regional.json) for exact provenance. Raw global rasters and original archive tables remain available through their producers; this repository includes the processed subsets the app loads.

## Partner and other data, assets and tools

- **Regional dust:** [LMD Mars dust climatology](https://www-mars.lmd.jussieu.fr/mars/dust_climatology/index.html), [MY36 v2.5 NetCDF](https://www-mars.lmd.jussieu.fr/mars/dust_climatology/dataset_v2/griddedcdod_MY36_v2-5.nc), [Montabone et al. methods paper](https://doi.org/10.1029/2019JE006111). Producer credit: Montabone et al. (2020), LMD/Space Science Institute, using NASA MRO/MCS v5.2 observations; MY36 v2.5 (2023). The derived JSON is a 26-date subset and format conversion; spatial bins, values, uncertainty and missing data are retained. **[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)** applies to this derived pack.
- **Rover visual:** [Mars Rover – Animated, PKO Studio, BlenderKit](https://www.blendkit.com/asset-gallery-detail/1618d58f-edbc-4ce7-b339-0f23c39bd945/). BlenderKit lists **Royalty Free**. Henri acquired this pre-existing asset and confirmed permission to use it in the public web project. The optimized GLB is a derivative for this app; the original Blender source is excluded. See [license scope](LICENSES.md).
- **Browser rendering:** [Three.js](https://threejs.org/), version 0.187.0, MIT.
- **Guided interface:** [Driver.js](https://driverjs.com/), version 1.3.6, MIT.
- **Pointer animation:** [Motion](https://motion.dev/), bundled from `framer-motion` 14.14.0, MIT.
- **Asset preparation:** [Blender](https://www.blender.org/), [Python](https://www.python.org/) and [Rasterio](https://rasterio.readthedocs.io/).
- **Verification and media:** [Playwright](https://playwright.dev/) and [FFmpeg](https://ffmpeg.org/). The distributed video is a captured application demonstration, edited for duration; no generated narration or music.
- **AI assistance:** [OpenAI Codex](https://openai.com/codex/), used as described in [AI_DISCLOSURE.md](AI_DISCLOSURE.md).
- **Experience reference:** [JPL Open Source Rover website](https://jplopensourcerover.com/) inspired the browser exploration approach. No site code, Hydra framework or artwork was copied.
